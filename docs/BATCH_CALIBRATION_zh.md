# 刚性夹具无线批量采集

`tools/batch_calibration.py` 使用 `requirements.txt` 中的 Python 依赖。各台共用夹具动作，各自在本机保存 ARC 观测。采集命令不复制其他设备的系数；联合求解和安装分别使用[求解器](JOINT_SOLVER_zh.md)与[CALWIRE](CALWIRE_zh.md)。CLI 也可通过新版 [Helper 十台面板](HELPER_FLEET_zh.md)调用。

## 当前完成范围

- 明确冻结接收器 USB 序列号及每台 RF 地址；每次操作先核对新鲜身份和传感器数据。
- 适配接收器单个控制邮箱：逐台等待执行回执，再启动下一台，各台采集可以重叠。
- 保存必须收到匹配设备、命令和本次序号的 CAL_STATUS `SAVED`。接收器 ACK、旧计数和 `EXECUTED` 均不替代保存证据。
- 保存命令前持久化意图；中断和超时标为不确定，不自动重发动作。支持显式 `--ids` 子集。单会话及同一接收器都有进程锁。
- USB 导出根据实际 RF 身份归档，完整数据经过现有 ARC8X1 解码器校验，同时保留参数读取文本。它不是完整 NVS 镜像备份。
- `tools/batch_orientation.py --session <会话目录> --slot <代表设备>` 可短暂读取一台的 F04 加速度摘要，自动识别当前朝上的轴和正负面。只用于夹具方向识别，不输入联合求解器；返回前核验摘要已停止，停止不确定时禁止继续校准命令。夹具上的所有设备仍须同向固定。
- `tools/batch_continuous.py` 增加整套 Earth/GSens 连续采集：用接收器 console 的逐设备邮箱快速下发命令，用主 HID 的逐台匹配 SAVED 作为动作屏障。明确选定一台 F04 监测同向刚性夹具的转动、静止和六面，通过本机中文语音提示动作；F04 不参与数值求解。掉线、身份变化、数据缺口、错误动作、异步失败或超时会停止流程并取消采集。取消引发的、精确匹配被取消命令的 FAILED/wrong-state 属于预期收尾；其他失败仍阻断。

## 连续流程的当前使用边界

用户要求只录制、不按姿态或等待时间打断时，使用 `tools/batch_record_only.py --session <会话目录>`。它核对接收器配对列表恰好等于冻结的整组 RF 身份，再启动整组 F04 录制；默认先等全部设备连续收到至少200个窗口才报告READY，动作须等READY后再开始，45秒未就绪会在开始动作前停止。旧固件或纯录制诊断可加`--passive`绕过该开始门槛。进入动作后所有完整HID报告持续落盘，数据缺口、重复、身份变化等记为诊断，不触发动作中断。它不发送ARC姿态保存命令，不播放语音，不修改生产系数。用户完成后，在`active-recording.json`指定的准确路径创建`STOP_RECORDING`，程序会停止无线摘要、核验停止回执并刷新文件及`quality.json`。硬件I/O或文件写入故障仍可能导致无法继续录制，不能承诺跨设备断电也不断流。

该模式是 **约 50 Hz、每窗口包含 8/9 个原始样本的积分摘要**，保存实际窗口时长和序号，不伪装成均匀 400 Hz 原始波形。整段录完后才能检查逐台缺口/重复与动作覆盖；保存文件本身不代表校准可用或参数已经安装。

新候选的严格TDMA、ACK重试和结束清单需要两端固件及宿主工具配套更新。具体行为、存储容量与重校准步骤见[采集可靠性](CAPTURE_RELIABILITY_zh.md)。

自动姿态脚本目前绑定本次夹具流程：初始 +X 朝上，默认已从原参考顺时针转 90°，所以第一条语音要求逆时针 90° 回到原参考；只有操作者明确确认原参考朝向，才能传 `--at-reference` 跳过恢复。**不能对任意新会话直接使用 `run`**；需要先根据实际参考位置调整入口。`preflight` 只查询/观察；`probe` 另启动再取消 Earth，不保存新姿态。正式 `run` 依次采集 Earth 的 0→90→180→90→0°，再独立保存 GSens 六面。每个姿态都要保持静止，直到所有设备保存且语音提示下一步；不再需要聊天确认。静默自动姿态模式也有等待/质量门控，不能用于用户明确要求“只录制、不要中断”的模式；该要求应使用上述 passive recorder。

旧固件把两点间的静止等待也积入 raw gyro 运动压缩与角度检查。宿主直接调用当前 C 核心，使用实测约 `[0.34,-0.1,0.03] dps` 零偏量级，复现了两分钟等待导致真实 90° 越出 60–120° 门槛。快速下发与即时自动引导减少这段等待；这是控制流程改进，并未修改固件门槛或证明所有旧失败都有同一根因。运动记录仍须在导出后通过更严格的重放与求解检查。

**已有实机闭环：** 十台无线快照、结合各台温补 LUT 的刚体联合求解、S/M/E 试用安装及全部重启回读；后续采集确认修复已通过十台静置零缺口试录。**尚未完成：** 全自动时钟／动作分段、完整批量 GUI 实机流程、独立精度、无线遮挡／重连和真实断电恢复验收。原逐台 Earth 门槛未通过，不能把试用安装写成质量通过。具体见[当前状态](STATUS_zh.md)。自动 USB 队列为可选增强，不是无线流程的前提。

## 创建会话

配置只放私有 `.local/`，内容形如：

```json
{"receiver_serial":"YOUR_RECEIVER_SERIAL","targets":{"0":"010203040506","1":"111213141516"}}
```

```powershell
& python tools/batch_calibration.py --session .local/batch/run-01 init --config .local/batch/fleet.json
& python tools/batch_calibration.py --session .local/batch/run-01 on
& python tools/batch_calibration.py --session .local/batch/run-01 reference-new
```

`reference-new` 开始新的归档参考，旧归档观测不再属于新参考，后续采集会替换旧观测；生效中的生产系数不变。需要保留旧归档时，应先按 CALWIRE 文档无线备份；USB 导出仍可用。不要在活动采集中执行。所有设备必须同向刚性固定，先放稳；每轮旋转前拔除追踪器 USB 线。

## 采集命令

在会话后指定 `temperature` 采集当前参考姿态的一个温度原始观测。它不是自动温补的 0.2°C 桶，也不能覆盖 15–43°C 全温区；范围和密度仍由固件的自动温补配置决定。失败会保留错误及逐台结果。

Scale 使用 `scale-x-start`、`scale-x-stop`，Y、Z 同理。启动前被测轴必须竖直。**现行无线协议只回报执行，不能回报 Scale 内部 READY**；命令接受不等于完成静止种子采样，不要在看到 EXECUTED 后马上转动。当前需要操作者保持稳定预备、明确收到开始动作提示，再准确转 20 圈并放稳；最终仍须匹配本次 stop 的 SAVED，才可计为已采集。没有 READY 遥测的限制尚未消除。

Earth 使用 `earth-start` 后五次 `earth-pose`，朝向依次 0°、90°、180°、90°、0°。GSens 单独回到参考朝向执行 `gsens-start`，随后六个不同朝上的面各执行一次 `gsens-pose`。没有开放 combined：旧协议在 Earth 第五次 SAVED 后才执行共享参考的第二次 NVS 写入，不能用第一次回执证明共享记录已经保存。

每次收到所有目标的保存结果后才移动夹具。不要用旧数据计数判断本轮完成。采集间通过 `status` 检查；结束使用 `off`。若某台失败，先查看对应 JSON 和 `radio.jsonl`，确认状态，必要时对该台 `cancel --ids N` 后重新开始该阶段；不要向已经完成的台盲目重放。

## 中断、导出与证据

`session.json` 是状态文件；各步骤单独保存在不覆盖的 JSON 中；`radio.jsonl` 保留命令意图、CRC 校验后的状态包及接收器回执。状态含 `inflight` 时拒绝继续写；先检查日志和进程，再执行 `recover` 将结果标为不确定。遗留锁不会自动抢占，须确认原进程已退出后人工移除准确锁文件。

USB 导出：

```powershell
& python tools/batch_calibration.py --session .local/batch/run-01 export-usb --port COM10
```

只有完整归档可使用此命令；缺数据或仍在采集时拒绝导出。导出目录以实际 RF 身份记录 USB 序列号、归档哈希及原参数文本。现阶段这些文件供后续核验，不触发生产参数安装。

测试：`python -m unittest discover -s tools -p "test_batch_*.py" -v`。宿主测试不证明实机旋转精度、全温区覆盖或批量参数安装。

Helper 的整组按钮逐台寻址并核对回执，参见 [Helper 说明](HELPER_FLEET_zh.md)。自动温度采集每次开机默认关闭，需显式开启；停止采集不会停用已有温表补偿。
