# 精度候选固件与验收

本轮把稳定低通移入 Tracker，补齐加速度坐标快照和参数恢复边界。十台已升级到 `e144bbfe183d_cw6_stable`，启动确认、二次重启与参数保持通过；独立角度、断电、热循环或功耗验收仍待完成。

## 已实现

- VQF 的 Butterworth 低通改为积分器状态实现，减少单精度 DF2T 在高采样率下的直流误差。截止频率和原有零偏学习参数保持原定义。`CONFIG_VQF_STABLE_IIR=n` 可构建旧实现作对照。
- 基线状态通过 retained 格式 ID 区分实现，Earth 状态通过版本和校验区分。旧状态不按新格式加载；无法恢复时走正常初始化。WoM 缺少有效世界参考时仍需回到固定参考姿态重启。
- CALWIRE TLV 4 v1 导出当前生效且与持久化值一致的加速度校准：`a_cal = A(a_raw-b)`，单位 g，坐标为传感器驱动输出轴。g-sens 使用 `M a_cal`，随后乘陀螺比例 S。
- 离线回放按已安装矩阵处理加速度和旧 M；旧快照缺少矩阵时明确标记未知，不能作为参数自动选择的安装依据。新加速度拟合同时报告已安装矩阵的误差，已有快照缺信息时该指标为空。
- 新拟合的原始坐标模型须同时变换 `M_cal=M_raw A^-1` 和 `B_cal=B_raw+M_raw b`。目前没有原子 M/B/加速度事务，完整原始 M/E/B 候选仅用于诊断；可写流程只接受有证据的比例更新，保留旧 M/E。
- 显式整组回滚增加全组预检；原始备份先落盘并同步，再打开设备。Flash 提交或读回结果不确定时，固件锁住本次运行的参数会话，保留 END 清理，要求重启后重新读取，不能将旧 RAM 作为持久化证据。

## 采集时间核查

保留原有时间算法。F04 积分用**发射端窗口时长**，排列、去重和缺口检查用发射端序号、boot、operation 与窗口结束时间。主机接收时间用于链路新鲜度和时钟初始拟合；原先的到达时间下包络为多设备时钟对齐提供整体速率参考，然后由十台共同运动细化。它不是逐包积分步长。

发射端时间目前是按实际配置采样周期累积的估计时间，并非已经标定的逐样本硬件时钟。去掉全部接收时钟参考会失去整体速率约束；因此未保留本轮尝试的纯运动时钟方案。延迟、批量到达、重传不能直接改变窗口积分；未知 FIFO 丢失、时间跳变、队列耗尽、重启和无法确定的录制尾部仍须拒绝用于常规校准。

## Helper 刷机后的顺序

1. 先选一台，保存当前 CALWIRE 快照和固件版本；保留现有接收器固件。选择候选目录中的 `tracker.signed.bin` 做 OTA，或使用 `tracker.signed.uf2` 做有线升级。仅适用于已有相同签名公钥、分区与 bootloader 的 Styria Mini nRF52840 SPI。
2. OTA 完整传输后按 Helper 提示手动重启。回到原始固定朝向和 +X-up 参考姿态，核对新版本、启动状态和 MCUboot 确认。不要同时执行校准或温度自动采集。
3. 再读快照，对比 S/M/E、温度表、档案和加速度参数。旧快照没有 TLV 4 时只能核对其已有字段；新固件下再做一组明确重启前后快照。`tools/verify_persistence.py` 比较同一设备的两个备份，输出字节一致性；它不会自行声称观察到了重启。
4. 固定参数做已知角度、不同速度与正反向测试，尤其是慢转后返回。记录每台误差、中位数、最差值；不要仅依据同一录制的回放指标决定升级全部设备。
5. 再做固定姿态的独立升温／降温完整循环、遮挡与 USB 慢主机录制、整夜佩戴和同条件电流／续航比较。确认没有启动、FIFO、无线或录制缺口后，才判断精度收益。

未启用快零偏、自适应静止学习、方向分比例、热迟滞、自动深睡或普通姿态包可靠重传。现有数据不足以证明这些策略在慢转、温漂和正常运动中普遍改善精度。

## 恢复

发生字段中断时，保留计划、备份、journal 和结果目录。重启／重新连接后只能恢复已知字段前缀；遇到其他变化停止，不覆盖未知参数。整组参数不是原子事务。

候选测试失败时可用包内记录的前一版签名镜像回退。固件回退不等于校准回滚；本轮软件准备没有写入设备参数。回退后同样回到固定参考姿态重启，并重新核对版本与快照。
