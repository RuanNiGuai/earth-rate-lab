# 改动内容、收益与代价

本页比较本项目演进前后的行为，**不把本地旧实验版本等同于当前上游**。对 jitingcn 当前源码的逐文件对照另见[上游差异](UPSTREAM_DIFF_zh.md)。现用版本见[状态](STATUS_zh.md)，尚未进入固件的算法单列。

## 功能对照

| 范围 | 改动前／问题 | 当前实现与优势 | 代价、缺点或边界 |
|---|---|---|---|
| 静止姿态突变 | 静止时单个肢体突然扭转，可长期保持；曾怀疑休眠唤醒 | 定位并避开 retained 区与启动栈冲突，保留／恢复融合相关状态；恢复静止后 FIFO 批处理 | 自动深睡仍关闭；三轮受控唤醒和短时观测不等于整夜、续航完成；不能把每次突变都归为同一根因 |
| 温度读数 | 无效标记、通信失败、离群温度可能进入采集 | ICM 无效值／包头修复；跳变暂存并多次一致确认，温度和零偏按窗口配对 | 连续错误但合法的读数仍可能通过；确认有延迟，旧污染点不会自动修好 |
| 温表配置 | 不适合此次使用温区和密度，可能无意持续采集 | `[15,43)°C` 每 0.2°C 观测桶；自动采集每次开机关闭，Helper 可开关并检查逐台覆盖 | 有效覆盖取决于真实经历温度，运行 LUT 仍为 0.25°C 网格，点更密不等于精度按比例提高 |
| 三轴比例采集 | 每台操作繁琐，累计起止存档看不到过程及正反差异 | 一组夹具、每轴五段连续录制：静止→正20圈→静止→反20圈→静止；保留全程数据 | 仍需正确轴向、圈数及牢固夹具；正反差异候选只诊断，固件仍为每轴单系数 |
| 联合运动模型 | 将各位置加速度视为同一轨迹会引入错误 | 共享角运动、独立安装及杆臂，含切向与向心项 | 缺外部真值时仍有规范自由度和参数耦合，不能靠十台平均消除所有系统误差 |
| 求解停止与目标 | 固定少轮迭代；残差随比例一起缩小，100ms 动态网格带宽不足 | 自动收敛停止、上限拒绝、传感器单位残差、20ms 角运动网格、稳健降权与信息量检查 | 计算时间与模型复杂度增加；达到收敛不等于物理模型正确 |
| 姿态分段 | 对死板十面顺序判断，合法换序也被拒绝 | 按真实姿态及信息量识别，可选末尾返回原面和航向，旧拒绝数据可重新分析 | 缺面、低激励、长断流或未知方向不能靠自动识别凭空补齐 |
| 采集通信 | 无线带宽有限、共享管道旧 PONG、重同步退避及主机反压造成停顿／缺窗 | F04 在设备先积分，保留未确认窗；接收器按身份确认入队，重传、心跳、时钟回退恢复及结束清单 | 不是十台同时原始 400Hz；ACK 到接收器，不到主机磁盘；缓存有限，无断电后日志持久化 |
| 普通 SlimeVR 流 | 丢包、状态混流、8位序号会出现缺口 | 保留低延迟策略和已有去重／重排处理；明确统计口径 | 不对所有普通姿态包逐包重传；不能承诺普通链路零丢包；接收端缺包不等同 MCU 融合漏样 |
| Windows 进度更新 | JSON 临时被占用导致 WinError 5，长录制被中断 | 进度更新可延后；关键状态有限重试；原始数据错误仍报错 | 界面可能短时不刷新，不能无限吞掉状态写失败 |
| Helper 使用 | 手选很多文件、顺序混乱，温度等按钮未完整接后端 | 五步向导、会话管理、真实温度命令与回读；单台全频和十台可靠采集并列 | 正常联合流程目前固定10台，其他台数未产品化；首次使用与多平台体验仍需验证 |
| 参数审阅 | 全量 Earth 未过导致连有效比例也无法写 | 新旧回放比较、分字段计划；当前只更新有证据的 S，M/E 精确保留 | 混合参数仍需整套回放，不能把不采用字段说成通过；已装加速度矩阵尚未导出 |
| 无线写入 | 重复点击仍比较写入前快照，成功后误报 Snapshot changed | 全组预检识别 before／after，完成设备只核验；失败仅回滚本次触及设备 | 三字段仍是独立 NVS 提交，不是整组原子事务；未知／中间状态拒绝写入 |
| OTA | Helper 只接 v1，当前固件为 ARC8 v2 | 48B tracker INFO、44B DATA、协议与板型检查；待手动重启独立显示 | v2 与 v1 的两端不能随意混用；接受激活不证明启动，新固件签名由 MCUboot 最终执行验证 |
| 融合数值候选 | 单精度低截止频率 DF2T 有抵消误差 | 等价状态变量低通在主机实测回放中有改善 | 仅实验；休眠状态不兼容、板上 CMSIS／功耗／时序尚待验收 |

## 最关键的取舍

**可靠采集与普通追踪分开。** 校准要完整时间积分和质量拒绝，普通姿态更重视及时输出；把全部追踪流改成可靠重传可能增加时延和功耗。设备侧预积分大幅降低带宽，但丢失窗内高频信息，故单台原始采集仍保留。

**保留完整证据，不以放宽门槛让流程看起来成功。** 原始录制、失败尝试、正反转诊断、输入与结果哈希、写前备份、逐字段日志均保留。建议新比例可单独使用，但不是强行把未通过的 Earth 或原始坐标 g-sens 写入。

**不按静置单项最优决定融合默认。** 快零偏学习与动态切换可让静置数字更好，同时吸收真实慢转；固定慢参考又可能拒绝温漂。当前保留生产 VQF，优先验证等价数值修正，完整反例见[实验总结](EXPERIMENTS_zh.md)。
