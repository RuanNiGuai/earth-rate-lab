# 用现有数据评估校准与融合

回放工具只读取文件、运行主机 C 回放器并保存报告，不打开 USB/RF。Helper 第5步现提供“回放比较并推荐参数”，随后单独审阅生成分字段计划；无需手选分析文件或重新录制。独立组件内置哈希绑定的生产版、稳定版别名、旧 DF2T 和 CMSIS 标量回放库，用户电脑无需安装编译器。开发 CLI 仍保留完整消融与原始高频验证入口。

2026-11-13：稳定实现已随 CW6 刷入十台，镜像确认、二次重启和参数保持通过，见[部署记录](DEPLOYMENT_20261113_zh.md)和[验收说明](ACCURACY_CANDIDATE_zh.md)。旧实验结果仍对应当时的源码哈希，不应按新 production 重新解释。新 CALWIRE 快照带已安装加速度矩阵时使用精确变换；旧快照只能作明确标记的诊断，不能自动推荐安装。

## 回放层次

`tools/fusion_replay.py` 直接编译当前 VQF/Earth C 核心，从生产源码提取参数初始化、运动零偏门控和加速度可信度判断。宿主适配器在 `tools/fusion_replay.c`。报告绑定来源文件 SHA-256。

支持两类输入：

* 十台 F04 连续积分窗：按区间重叠保积分重采样到 50 Hz；可重复窗内均值模拟陀螺 400/加速度 100 Hz 的滤波更新，**不恢复窗内运动或高频噪声**。
* RAWFIFO-v1 原始数据：每个有效陀螺包更新，只有新加速度标记时才更新加速度，不将旧样本冒充新观测。当前验证资料按 409.6/102.4 Hz 标称时间回放；FIFO 读取完成的批次时间不被当作逐样本采样时间。

融合前的 Earth/g-sens 拟合残差不是 VQF 输出误差。在线零偏跟踪可以降低最终静置漂移，但也可能吸收真实缓慢运动，必须同时比较运动保持和静置指标。

## 十台数据比较

```sh
python tools/jointcal/optimize_fusion.py --input /path/to/input.json --result /path/to/result.json --out /path/to/new-review
python tools/jointcal/optimize_fusion.py --input /path/to/input.json --result /path/to/result.json --out /path/to/fixed-comparison --iir stable --confirm-policy conservative
```

输入是原联合校准的哈希绑定输入和结果。工具比较旧参数、新比例、再加入新 g-sens、保留旧 Earth/换新 Earth/关闭 Earth，以及十台共享重力约束的加速度零点和对角比例候选。加速度求解固定原联合安装旋转；没有从六面数据声称辨识任意非正交矩阵。

融合参数只用 X/Y 正向旋转及部分静置选择，Z、反向旋转和后续姿态单列。由于校准参数原本使用了四份录制，这不是整套校准的独立精度验收。比较结果必须进一步由独立录制和已知动作检查；不能仅凭最小 training_score 安装。

`--confirm-policy` 使用固定候选与同一数值实现的 baseline 比较，不再搜索参数；输出 `confirmation.json`，按 400/100 Hz 重复子步运行。`conservative` 只是保持原零偏学习速度的实验名称，不代表所有条件更安全。生产版已采用稳定低通，`--iir stable` 保留为兼容别名；旧实现对照使用 `Replay(..., iir="legacy")`，CMSIS 标量对照使用 `Replay(..., math_backend="cmsis")`。

重要边界：旧 CALWIRE 快照未包含加速度 `accBAinv`，只能做明确标记的原始数据诊断；CW6 的 TLV 4 已导出该矩阵，回放按 `A(a_raw-b)` 重建安装坐标，并报告已安装矩阵的加速度误差。F04 仍是原始窗口均值，不能因此称为全固件逐样本重现。新 g-sens 若要用于修正后的加速度坐标，必须做相应仿射变换，不能直接复制原始坐标中的矩阵。现阶段不自动写入这些参数。

## 独立原始采样验证

```sh
python tools/validate_fusion.py --raw-session /path/to/session.json --out /path/to/confirmation
python tools/validate_fusion.py --raw-session /path/to/session.json --out /path/to/stable-confirmation --iir stable
python tools/validate_fusion.py --raw-session /path/to/session.json --out /path/to/fixed-raw-comparison --iir stable --policy baseline --policy conservative
```

会话格式为此前单台校准的 `joint-calibration-session-v1`。仅使用 `mechanical_stationarity_confirmed=true` 的条目，遵循有效设备时间与温度上限；初始 15 秒留作滤波器建立。确认原始文件 SHA、包序号、完整性与新加速度节拍。过短片段记录跳过理由，不能拼接断流并压缩时间。

单台原始数据只验证通用融合策略，不代替十台联合校准，不套用其他设备的温表或系数。报告包括真实静置及合成慢转、线加速度场景；慢转与零偏产生相同 IMU 信号时没有普适区分方法。

实验候选包括：

* `biasSigmaRest=0.005°/s`，使静置残余零偏跟踪更快；其效果与过程噪声/forgetting 参数相关。
* 独立的 60 秒慢变参考，0.03°/s 的偏离门槛，避免快速偏置估计先吸收运动、再以自身证明静止。前 15 秒属于初始化假设；真零偏突变或更慢的真实转动仍可能混淆。
* 角速度门控同时检查加速度模长。合加速度模长恰好仍为 g 的线加速度无法因此被识别。

`baseline` 保持原参数；`conservative` 使用慢变参考和联合加速度门控，但保留 `biasSigmaRest=0.0153°/s`；`slow_anchor` 再将它减至 `0.005°/s`。`--policy` 可重复指定固定比较集合，省去不需要的回放。

这些阈值属于候选，不是自动生成的固件配置或已验证的通用最佳值。

## 稳定数值低通实现

生产源码现已采用等价二阶 Butterworth 梯形积分状态变量实现，降低单精度 DF2T 在高采样率/低截止频率下的抵消误差。`--iir stable` 指向同一生产分支，历史源码变换保留用于复现旧实验。对应的 Earth 启动偏置/低通状态平移也一起变换；只替换滤波公式而不转换 Earth 历史会产生重复或错误补偿。

两种实现的状态字节**不兼容**，即使大小相同。候选已增加格式版本、拒绝旧休眠快照，并通过主机保存/恢复、Earth 启动和重对齐测试。CMSIS 标量路径也已对照，板上数值、CPU 耗时和电流仍待实测。动态 tau 保持关闭。

## 2026-11-12 已有数据的取舍

单台旧校准 RAWFIFO 中，17 段机械确认静置的有效数据共 2,398,324 个陀螺样本，97.59 分钟。仅改变低通数值实现，五秒姿态增量漂移 RMS 的跨段中位数从 0.24278 降为 0.19404°/分钟，17 段均改善；最差一段仍为 1.47681°/分钟。它不是整夜累计漂移，也没有使用当前十台的温补。独立十台约 25 分钟静置数据上，此数值改动的收益很小（0.15651 → 0.15618°/分钟），不能把单台的 20% 推广到所有设备。

快零偏加慢转保护在十台独立静置上降至 0.10458°/分钟，但旧腕部回位指标从 11.411° 增为 11.674°。保持原学习速度的保护方案在十台校准留出段改善回位，却在旧单台持续降温的一段中由 0.34669 恶化为 1.04116°/分钟：慢变参考落后后，真实零偏变化被拒绝，不能直接作为默认。

因此优先保留等价低通的数值修正候选；更快零偏和慢转门控只作为实验。0.01°/s 的真实慢转仍会被明显吸收，模长接近 g 的持续线加速度仍可能误导重力方向。已有录制对这些不可辨识情形没有外部真值，不继续用验证集反复调参来宣称通用最优。

地球方向继续十台共享、纬度已知。原逐台 0.001°/s 门槛评估的是融合前总残差，不能据此要求六台分别补出新地球方向。现有新旧方向及组合回放支持先保留旧 Earth；新比例是运动回放中最大收益来源，新 g-sens 增益较小。Helper 推荐路径只允许验证后的新比例，地球和 g-sens 按备份字节保留；新字段全量安装还需支持 M/B/加速度仿射事务，当前仅诊断。具体筛选与写入保护见 [Helper 流程](HELPER_FLEET_zh.md)。

2026-11-13 腕部校准复核：旧 11.31° 是采用 10 月 29 日旧比例的诊断回放。同一原始输入改用这台设备已安装的比例为 2.098°，再加入当前完整补偿为 2.048°；参数未用这段腕部数据重新拟合。剩余约 2° 和安装后的独立实测仍待验证，详见[腕部误差分析](WRIST_RETURN_20261113_zh.md)。

### 运动复核及动态学习

仅稳定低通：旧腕部人工回位由11.41117°变为11.31073°，减少0.10044°（约0.88%）；十台后段回位 RMS 0.7286958° → 0.7286926°，基本持平。这些是人工返回一致性指标，没有外部角度真值，不能把静置中位数的20.1%收益称为运动精度提升。

另实现 `adaptive_rest`：连续可信静置30秒后，在随后30秒渐进把 `biasSigmaRest` 从0.0153降至0.005°/s；检测活动即回到原学习速度，姿态及零偏状态不中断。十台后段回位为0.69941°，但旧腕部退至11.42747°；合成真值18°慢转只输出1.446°，4.5°只输出0.362°。该策略只供回放，不进入设备默认参数。静止与绕重力轴的匀速慢转可能产生相同IMU观测，动态切换不能解除这个可辨识性限制。

## 尚待实机的最小验证

已有数据先完成静置、温变、不同姿态、运动回位及慢转反例，避免额外校准动作。候选刷机后再测：

1. 已知方向的缓慢旋转和返回，尤其 0.01–0.2°/s；同时记录可信外部角度或机械标记。
2. 长静置与活动交替、不同温度、姿态恢复，以及快速线加速度后的恢复。
3. 实际 400/100 Hz 调度、FIFO/时序计数，休眠前后连续性、处理时间及功耗。

复用原单台全频录制程序与十台可靠采集程序即可；本工具不自行连接或刷写设备。源码回放支持通用主机数学库和 CMSIS 标量子集，均不能替代上述硬件验收。
