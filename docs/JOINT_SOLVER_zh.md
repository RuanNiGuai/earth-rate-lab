# 十台刚体联合求解

入口为 `tools/jointcal/`，不访问硬件。支持固定的十台同向刚性夹具：三轴各一轮「静置、20圈、静置、反向20圈、静置」连续录制；随后五个参考面航向静置和补齐六面，共10个静置段，并支持可选第11段回到最初面及航向。四份录制一起处理，各设备位置不同，模型分别估计切向和向心加速度项。旧单向累计存档仍可通过高级输入使用。

## 自动连续输入

Helper 普通向导调用 `continuous.py`，管理四份 F04 数据，无需用户选择时钟与分段文件。先核验十台首尾及内部零缺口和结束清单，再用到达延迟下包络初始化时间尺度、以十台共同角运动细化偏移／漂移。归一化使用速度大于5°/s的运动样本的75%分位数，至少101个运动窗口，不再用全程95%分位数把长静置误判为缺少运动。识别稳定静置区间并留出两侧过渡余量；三轴必须各三段静置、两段反向旋转，姿态录制包含十段或增加返回段的十一段。具体面及航向覆盖规则见下文。

配置仍为 `JOINT10_INPUT1`，新增 `recordings` 四份来源哈希和 `scale_captures` 三轴逐台数组及静置区间。比例拟合逐窗口扣除温补和各台 g-sens，以相邻静置零偏插值，十台共同约束两方向各7200°。

各方向候选与温度／转速／静置信息保留在 `iterations[].scale.direction_checks`。当前安装使用每轴单一系数；方向差异超过0.2%、共同角度RMS超过7.2°或地球回环超过3°时拒绝普通安装计划。正负系数候选用于后续固件分析，不修改现行存储格式。完整窗口仍不能恢复20ms内部全部锥运动，也不能独立证明用户数对了20圈。

可复现全流程合成录制（标记为 synthetic，禁止安装）：

```sh
python tools/jointcal/continuous_example.py --out .local/continuous-example
python tools/jointcal/continuous.py --recordings .local/continuous-example/recordings.json --snapshots .local/continuous-example/snapshots --latitude 45 --out .local/continuous-input
python tools/jointcal/joint_rigid_v3.py --config .local/continuous-input/input.json --out .local/continuous-result
```

45°是例子真值，实测须填写实际纬度。录制、对齐报告、每台NPZ与快照哈希全部保留；失败不覆盖历史文件。

生成器增加 `--final-return` 可验证完整十一段流程。配置以 `final_return_present: true` 标记末尾返回，静置数组须有11段；未设置时保持10段兼容，不根据数组长度猜测或重排时间线。

## 合成例子

```sh
python tools/jointcal/example.py --out .local/example
python tools/jointcal/joint_rigid_v3.py --config .local/example/input.json --out .local/example-result
```

输入为固定种子的无噪声数学模型，有10个不同位置。生成器保留 `truth.json`，输出永远是诊断候选，不是硬件安装许可。`python tools/check.py` 还包含安装方向、时钟、积分区间、比例和地球／g-sens的合成回归。

## 高级手工输入与旧录制

先按[无线文档](CALWIRE_zh.md)取得全部设备的 `snapshot.bin`，并按[批量文档](BATCH_CALIBRATION_zh.md)保存 F04 `reports.jsonl`。准备两个JSON文件：

- 分段：`{"static_segments_s": [[起始秒,结束秒], ...]}`，严格10段，每段至少12秒，依次为Earth五航向、-X、+Y、-Y、+Z、-Z；第一段+X已计入六面。
- 时钟：`{"clock_models": [{"tracker":0,"clock_rate_correction_ppm":0,"offset_seconds":0}, ...]}`，包含0–9全部设备。offset映射每台首个设备时间到同一主机相对时间原点；从设备时间乘以`1+ppm×1e-6`再加offset。应从对应录制的主机时间和设备时间独立估计，不能照抄零值。求解会在此基础上细化相对偏移和速率。

```sh
python tools/jointcal/prepare.py --recording .local/run/reports.jsonl --clocks .local/clocks.json --segments .local/segments.json --snapshots .local/backups --latitude 45 --out .local/inputs
python tools/jointcal/joint_rigid_v3.py --config .local/inputs/input.json --out .local/result
```

45°只是命令示例，使用实际纬度。prepare默认从原报告重新核验全部设备的结束清单及首尾/内部零缺口，未通过时拒绝继续；详情见[采集可靠性](CAPTURE_RELIABILITY_zh.md)。旧录制没有结束清单时，可显式加`--allow-legacy-transport`做诊断，不宣称传输通过。prepare不自动判断动作是否正确；重复报告去重，冲突重复和重启／会话切换被拒绝，缺失保存在`integrity.json`，传输门槛另存`transport-quality.json`。时钟模型和人工分段仍需独立检查；这是显式输入步骤，不是全自动动作识别。

`JOINT10_INPUT1`配置把每台NPZ、快照及原录制SHA256绑定起来。NPZ单位：time／interval_end／duration为秒，gyro为°/s，accel为g，temp为°C，seq为窗口序号；记录有真实时长且按时间排序。快照由现行CALWIRE解码器重新校验，不信任手工修改的backup.json字段。

## 求解与质量

以0号定义参考坐标，按十台重力方向共同估计安装旋转。用真实积分区间拟合共享角速度并细化时钟；比例使用7200°约束。Earth模长0.0041780746°/s，纬度显式给定，g-sens每台独立。各台加速度保持独立，并估计相对力臂，模型项为 `α×r + ω×(ω×r)`。当前求解器版本为 `adaptive-window-rigid-1`。

### 分块交替细化

每一轮依次更新以下部分，然后检查参数与目标是否稳定：

1. 三轴比例与安装方向：六个已知正反20圈积分给出绝对角度基准，同时利用上一轮的连续窗口约束。窗口公共曲线允许共同的3×3线性修正，防止由同一批设备估出的曲线把绝对比例锁死在初值上。
2. 各次录制独立的时钟偏移／速率与共同角速度曲线：十姿态转换与三轴长旋转均使用20 ms网格，每个实测窗口按真实起止时间积分比较。旧版长旋转100 ms网格会漏掉转速快速变化，其模型带宽误差不能归咎于操作终点或传输缺口。
3. 十台不同位置的刚体加速度：三轴六段长旋转与十姿态九段转换共同提供激励；估计相对位置及加速度残余常量偏置。各台使用各自的切向／向心项，不能把所有设备的加速度简单平均成同一点轨迹。
4. 连续窗口反馈与静置联合拟合：刚体预测与该台实测加速度一致时用于降噪，偏离时自动减小预测权重；逐窗口陀螺残差采用Huber降权。窗口回归方程通过加权QR压缩为少量充分统计行，再反馈比例与g-sens拟合；QR保留对应加权最小二乘目标，不生成额外观测。静置方程共同求地球水平相位、每台g-sens、常量零偏和缓慢时间漂移。

刚体混合权重为 `1/(1+(加速度残差/0.003g)^2)`。窗口陀螺噪声尺度下限为0.02°/s，按0.2秒有效独立间隔计权，避免将相邻50 Hz摘要视为完全独立证据。静置训练半段按0.5秒分块，从相邻块均值差的MAD估计噪声，均值标准误下限0.0002°/s；IRLS对异常静置段降权，参数变化 <10⁻⁷ 且权重变化 <10⁻³ 时停止，100次只作上限，避免原12次上限提前截断实测数据。时钟细化使用窗口积分对偏移和速率的解析导数，避免小ppm差分产生的浮点消减误差；时钟边界与收敛门槛不变。这些是工程权重与下限，仍需用实测重复录制校验。

窗口反馈及其噪声估计使用传感器测量坐标和原始陀螺单位：将共同角速度反向旋转并除以待估比例，与去掉g-sens后的陀螺测量比较。旧公式把测量及其不可解释残差一起乘以待估比例；即使公共曲线允许整体变换，缩小比例也能降低那部分残差，从而拉偏7200°约束。这是目标函数的尺度偏差。修复没有增加20圈权重或放宽验收门槛；数值修订标记为 `sensor-residual-window20ms-2`，旧修订的结果须用原录制重新求解后才能生成新安装计划。

`joint_angle_rms_deg` 是十台、六段旋转、三个分量的积分向量残差RMS，**不是放回原位时的姿态误差**。新增 `turn_axis_rms_deg` 单独报告沿共同旋转轴的总角度残差，`turn_transverse_norm_rms_deg` 报告横向向量残差，二者满足 `3×joint_angle_rms_deg² = turn_axis_rms_deg² + turn_transverse_norm_rms_deg²`。横向残差包含轴方向／模型不一致，不能直接解释为实际少转或多转；这些拟合内指标也不是独立角度真值。原7.2°安装门槛仍针对三分量RMS，保留定义，没有换指标冒充改善。

### 自动停止

主循环默认最多30轮，至少4轮；最近连续3次变化必须同时满足下表，且内部比例、时钟、角曲线、刚体与稳健静置求解均成功。内部时钟／曲线交替也按变化量停止，最多8次；时钟修正触及约±15 ms或±50 ppm边界不算通过。

| 检查量（全十台、所有相关录制中的最大变化） | 停止阈值 |
|---|---:|
| 比例相对变化 | 2×10⁻⁶ |
| g-sens元素变化 | 2×10⁻⁶ °/s/g |
| 安装旋转变化 | 0.001° |
| 相对时钟偏移变化 | 10 μs |
| 相对时钟速率变化 | 0.05 ppm |
| 地球水平相位变化 | 0.001 rad |
| 相对位置向量变化 | 0.5 mm |
| 固定量纲缩放目标的相对变化 | 0.2% |

停止目标同时包含已知角度、静置、动态角速度和刚体加速度的原单位残差，经固定尺度归一；不以稳健权重下降冒充残差改善。`--max-iterations`只是安全上限，达到上限仍未稳定时输出诊断、标为未收敛。Helper普通向导不接受该结果；高级离线`solve`可保存诊断，但安装计划即使加`--trial`也不能越过收敛门槛。旧求解结果须由新版本重新计算。

`convergence.json`与`result.json`包含阈值、每轮变化和停止原因；`window-refinement.json`包含各动作／设备的噪声尺度、降权比例、刚体混合权重及内部求解状态；原始数据与正负方向候选全部保留。

### 信息量与验收

建议前五段地球静置各90–120秒，补齐六面的后五段各约30秒，末尾可再恢复最初 +X 面及边的航向并静置90–120秒。返回段拓宽零偏／线性漂移的拟合时间跨度，训练半段参与静态方程，后半段仅作该模型的留出诊断。`final_return` 报告首尾积分姿态闭合角、每台重力方向夹角、扣除g-sens后的首尾陀螺差、拟合漂移和末段留出残差。积分不会强制闭合到单位旋转；仅重力同向不能检查绕重力轴的航向。含返回段时，闭合角和逐台重力夹角均须≤3°；不满足时连试用计划也须先检查返回动作或模型，不能以 `--trial` 绕过。该边界仍依赖同一批设备与拟合参数，不是独立姿态真值；延长静置也不能保证消除低频漂移。

地球项不能仅因模型固定了理论模长就被视为可辨识。除原残差门槛外，另计算未强制固定幅值的水平分量：其幅值与理论水平幅值之比须在0.5–1.5，投影设计秩须为2，条件线性化相位标准差须≤30°；每台静态／窗口联合设计秩须为5、条件数须小于10⁶。报告同时保存各台g-sens条件标准误。上述不确定度固定了比例、时钟和安装方向等其他参数，不能当作整体误差条或实机精度。

连续录制的动作准入按实测重力面与积分航向判断，不强制后五面顺序。前五段仍要求 +X 朝上、相邻约90°、最终回到起始航向；允许反向回环。准备阶段将五段航向的 cos/sin 设计投影去除常量和按实际静置中心时间建立的线性漂移，每台的最小奇异值须 >0.2、条件数 <20；粗积分回环误差须 <15°。这是几何信息预检，不代替求解后的幅值、噪声及3°回环安装门槛。后五段必须覆盖其余五个面，各台重力方向与识别面点积须 >0.92。识别顺序、近似航向与几何信息量保存在 `poses-analysis.json`。例如 0°、90°、180°、90°、0° 可能通过预检；0°、90°、0°、90°、0° 无法提供两个独立水平分量。所有区间保留原始时间顺序，六面拟合使用实测加速度，不能按标签重新排列时间线。

静置前半段拟合、后半段留出；另报告整个姿态省略与动作留出。十姿态中索引3、7的动作（从0开始）不参与时钟、杆臂训练及窗口反馈；其共同曲线仍参与姿态重建。整姿态省略仅重拟合静态模型，停用含该静置基线的动态QR，但复用本次全数据估计的比例、安装方向及时钟。因此这些是部分留出诊断，不能称为完全独立验证。默认诊断不会写参数，也不会因全组平均较好而自动越过逐台门槛。每台Earth训练和留出RMS均须≤0.001°/s、g-sens均须≤0.006°/s，还要通过温度支持、参数物理范围及正反方向等门槛。信息量失败会阻止常规安装；高级命令的明确试用例外仍保存失败项，但不能绕过未收敛或温度覆盖不足。

这是分块交替求解，自动收敛表示数值稳定，不保证全局最优。末轮运动模型使用本轮g-sens更新前的值，两者差异受停止阈值约束；未收敛结果不可安装。弱激励下的杆臂可能依赖先验，位置未经实测，也没有独立位置精度证明。温度LUT本轮保持固定，不重新估计迟滞、长期温漂或完整VQF行为。

输出`result.json`始终保留`installable=false`，安装需要另行审查和[明确的安装计划](CALWIRE_zh.md)。缺失窗口上的拟合值仍是模型预测；同一次采集内的静置前后半段相关，不是独立热循环／外部姿态真值。
