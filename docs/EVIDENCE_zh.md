## 指标定义

- **静态角速度RMS（°/s）**：融合前补偿残差，与最终姿态误差不同；是否去除起始零偏／全段拟合慢漂必须标明。
- **20圈积分三分量RMS（°）**：积分约束的向量分量残差；与沿轴角误差、单圈等效值、最终四元数误差不同。
- **回位RMS（°）**：指定稳定窗口间的姿态返回差；真实数据多为人工返回，没有外部角度真值。
- **校准后段静置（°/分钟）**：每段前后稳定窗口的姿态差除以间隔，与下面五秒增量统计不是同一定义。
- **五秒姿态增量漂移RMS（°/分钟）**：初始15秒后计算固定五秒间隔的姿态增量率，再做RMS；单台高频表用跨段中位数，十台长静置用整组RMS。
- **无缺口**：指定录制内按协议序号、设备计数、接收器计数和主机保存对账通过，不表示无空口重发，也不表示姿态真值准确。

RMS、中位数、最大值不能互换；“平均改善”不意味着每台改善。百分比只在相同定义与数据上计算，不跨表相加。

## 公开可运行的验证入口

```sh
python tools/check.py
python tools/jointcal/example.py --out .local/example
python tools/jointcal/joint_rigid_v3.py --config .local/example/input.json --out .local/fit
python tools/fusion_scenarios.py --out .local/fusion-scenarios.json
python tools/release_export.py --check-only
```

有自己原始数据时，按[回放说明](FUSION_REPLAY_zh.md)运行 `validate_fusion.py`、`optimize_fusion.py`；不要拼接断流并压缩时间，不要把FIFO批次完成时间当逐样本时间。十台刚体约束只在夹具上成立，穿戴在不同肢体后不成立。
